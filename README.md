# Student Result Management System 🎓

A simple **console-based Student Result Management System** developed using Core Java. This project automates student result calculations and demonstrates fundamental Object-Oriented Programming (OOP) concepts.

## 📌 Project Overview

The Student Result Management System allows users to enter student details and examination marks, calculate academic results, display student records, and search for students using their roll numbers.

The project is designed to reduce manual calculation efforts and provide a simple way to manage student results.

## ✨ Features

- Enter details of multiple students.
- Store student roll number and name.
- Input marks for five subjects.
- Calculate total marks automatically.
- Calculate percentage.
- Assign grades based on percentage.
- Determine PASS or FAIL status.
- Display complete student results.
- Search student records using roll number.

## 📊 Grading Criteria

| Percentage | Grade |
|---|---|
| 90% and above | A+ |
| 80%–89.99% | A |
| 70%–79.99% | B |
| 60%–69.99% | B+ |
| 40%–59.99% | C |
| Below 40% | F |

**Pass/Fail Rule:** A student must score at least 35 marks in every subject to pass. If the student scores below 35 in any subject, the final result is FAIL.

## 🚀 How to Run the Project

### Prerequisites

- Install Java JDK 21 or a compatible version.
- Install Visual Studio Code.
- Install the Extension Pack for Java in VS Code.

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Student-Result-Management-System.git
   ```

2. Open the project folder in VS Code.

3. Open the terminal in VS Code.

4. Compile the Java program:

   ```bash
   javac StudentResultManagement.java
   ```

5. Run the application:

   ```bash
   java StudentResultManagement
   ```
